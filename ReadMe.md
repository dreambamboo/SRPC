# Subtype-Aware Residual Prognostic Calibration for Histopathology-Based Survival Modeling in Small-Cohort Rare Diseases

This repository contains release code for **Subtype-aware Residual Prognostic Calibration (SRPC)**, a survival modeling framework for whole-slide histopathology in small-cohort rare diseases. The prognosis part is inference-only: users provide their own WSI-derived feature paths, and the released SRPC checkpoints in this repository are used to reproduce the reported Table 1 predictions and metrics.

**Note.** This open-source package was reorganized with AI assistance from the working research codebase rather than exported directly from the original experiment repository; despite careful checking, some omissions or mismatches may remain, so please review and adapt it according to your actual application needs.

## What Is Included

```text
my_opencodes/
  ReadMe.md
  requirements.txt
  wsi_feature_extraction/   # CLAM-based WSI patching and encoder feature extraction
  data/                     # metadata, manifest examples, subtype labels, and fixed fold splits
  srpc_survival/            # inference-only SRPC prognosis code
  my_checkpoints/           # released SRPC prognosis checkpoints used for Table 1
```

This repository includes prognosis checkpoints only. The following large external resources are **not** included and must be provided by the user through command-line paths:

- raw WSI files, such as TCGA `.svs` slides;
- extracted feature tensors, such as `*_pt_path` files in the manifest;
- public encoder weights for ResNet50, UNI2-h, and TITAN/CONCH v1.5;
- third-party backbone repositories required by some checkpoints: TransMIL, DTFD-MIL, MambaMIL, and TPMIL.

## Installation

Create a clean Python environment and install dependencies:

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

If your machine has a specific CUDA/PyTorch requirement, install the matching PyTorch build first from the official PyTorch instructions, then install the remaining packages.

## Data Download

The paper experiments use TCGA diagnostic WSI data. Download raw slides according to the GDC data-use rules:

- TCGA-SARC project page: https://portal.gdc.cancer.gov/projects/TCGA-SARC
- TCGA-MESO project page: https://portal.gdc.cancer.gov/projects/TCGA-MESO
- GDC Data Portal repository: https://portal.gdc.cancer.gov/repository
- GDC Data Transfer Tool: https://gdc.cancer.gov/access-data/gdc-data-transfer-tool

A typical GDC filter is: project = `TCGA-SARC` or `TCGA-MESO`, data category = `Biospecimen` or `Clinical` for metadata, and data category = `Slide Image`, data format = `SVS` for pathology slides. The folder `data/` contains the slide lists, subtype labels, manifest examples, and fixed fold splits used by this release.

## Encoder Weights for Feature Extraction

Store external encoder checkpoints in a user-selected folder and pass that folder with `--checkpoints_root` during feature extraction. A recommended layout is:

```text
encoder_checkpoints/
  resnet50/pytorch_model.bin
  uni/pytorch_model.bin
  TITAN/
    config.json
    configuration_titan.py
    modeling_titan.py
    conch_v1_5.py
    conch_tokenizer.py
    tokenizer.json
    conch_v1_5_pytorch_model.bin
```

Download links:

- ResNet50 ImageNet weights: https://download.pytorch.org/models/resnet50-11ad3fa6.pth
- UNI2-h: https://huggingface.co/MahmoodLab/UNI2-h
- TITAN / CONCH v1.5: https://huggingface.co/MahmoodLab/TITAN

Some Hugging Face models may require account access approval. Download them once on an authorized machine, then copy the files into the layout above.

## Feature Extraction

Example command for TCGA-SARC slides. The input slides, encoder checkpoints, and generated features all live outside this code repository:

```bash
python wsi_feature_extraction/run_clam_feature_pipeline.py \
  --dataset SARC \
  --source_dir /path/to/SARC/slides \
  --results_root /path/to/extracted_features \
  --checkpoints_root /path/to/encoder_checkpoints \
  --encoders resnet50_trunc uni_v2 conch_v1_5 \
  --patch_level 1 \
  --patch_size 512 \
  --step_size 512 \
  --batch_size 128 \
  --num_workers 8 \
  --device cuda
```

The default setting assumes OpenSlide level 1 corresponds to x20. Please verify the level-to-magnification mapping for any new dataset.

After feature extraction, create or edit a manifest CSV outside the repository. It should contain at least:

```text
slide_id, patient_id, subtype, PFI, PFI.time,
resnet50_trunc_pt_path, uni_v2_pt_path, conch_v1_5_pt_path
```

The feature-path columns must point to the external `.pt` files generated by feature extraction. Manifest examples are provided in `data/SARC/` and `data/MESO/`.

## SRPC Inference on Released Checkpoints

For most users, use `srpc_survival/run_srpc_inference.py`. It loads the released checkpoints from `my_checkpoints/`, reads your external manifest, predicts on the selected folds, and writes predictions plus metrics to an external output directory.

Example: reproduce all Table 1-style SARC results from external features:

```bash
cd /path/to/my_opencodes
python srpc_survival/run_srpc_inference.py \
  --manifest /path/to/SARC_survival_feature_manifest_with_external_features.csv \
  --split_dir data/splits/SARC/5fold_pfi_seed2026 \
  --checkpoint_root my_checkpoints \
  --output_dir /path/to/srpc_outputs/SARC_table1 \
  --backbones all \
  --encoders all \
  --folds all \
  --endpoint PFI \
  --device cuda \
  --transmil_dir /path/to/TransMIL-main \
  --dtfd_dir /path/to/DTFD-MIL-main \
  --mambamil_dir /path/to/MambaMIL-main \
  --tpmil_dir /path/to/TPMIL-main
```

Example: run only ABMIL + ResNet50:

```bash
cd /path/to/my_opencodes
python srpc_survival/run_srpc_inference.py \
  --manifest /path/to/SARC_survival_feature_manifest_with_external_features.csv \
  --split_dir data/splits/SARC/5fold_pfi_seed2026 \
  --checkpoint_root my_checkpoints \
  --output_dir /path/to/srpc_outputs/abmil_resnet50 \
  --backbones abmil \
  --encoders resnet50_trunc \
  --folds all \
  --device cuda
```

The script writes:

```text
output_dir/
  fold_metrics.csv
  summary_metrics.csv
  <backbone>/<encoder>/fold<k>/predictions.csv
  <backbone>/<encoder>/fold<k>/decomposition.csv
```

`evaluate_table1.py` is kept as a backward-compatible wrapper around `run_srpc_inference.py`.

## Third-Party Backbone Code

The released SRPC checkpoints wrap several public MIL backbones. Download these official repositories outside this code repository and pass their paths only when needed:

- TransMIL: https://github.com/szc19990412/TransMIL
- DTFD-MIL: https://github.com/hrzhang1123/DTFD-MIL
- MambaMIL: https://github.com/isyangshu/MambaMIL
- TPMIL: https://github.com/LitaoYang-Jet/TPMIL

ABMIL checkpoints do not require an external backbone repository.

## Reproducibility Note

ABMIL, MambaMIL, TPMIL, and TransMIL checkpoints reproduce deterministically with the released inference code. DTFD-MIL performs stochastic instance grouping in its original forward pass, so its recomputed metrics can show very small numerical fluctuations unless the original saved predictions are reused.
